# Privacy Team README


# Privacy Team

This module performs privacy analysis for the CAPSS project. It analyzes registration logs, computes privacy metrics, detects privacy threats, generates reports, and creates visualization graphs.

---

# Folder Structure

```

project/
│
├── logging/
│   ├── metrics_collector.py
│   └── registration_logger.py
│
└── privacy/
    ├── run_privacy_pipeline.py
    ├── security_context.py
    ├── correlation_analyzer.py
    ├── metadata_minimizer.py

    ├── privacy_summary.py
````

Output files are written inside the **results/** directory.

# Before Running

Normally, you **do not need to modify anything**.

Only make changes if:

- You are using a **different registration dataset**, or
- You are using a **different AMF implementation**, or
- The input file names or locations have changed.

Otherwise, simply continue with the pipeline.

---

# Running the Privacy Pipeline

Run:

```bash
python run_privacy_pipeline.py
````

The pipeline automatically executes all required privacy scripts in the correct order.

---
# Pipeline Execution Order

The pipeline executes the following scripts in the order shown below. The order is dependency-driven.

---

## 1. metrics_collector.py

Runs first.

Collects performance metrics during the registration process, such as execution time and other runtime statistics. It generates `metrics_report.txt` to help analyze the performance of the registration workflow.

---

## 2. registration_logger.py

Runs after the metrics collector.

Records all registration events and creates the registration dataset used by the privacy pipeline. This dataset serves as the primary input for all subsequent privacy analysis modules.

---

## 3. security_context.py

Runs after the logging modules.

It merges the attack context into the registration dataset and generates `privacy_dataset.csv`.

The following fields are added:

- Attack_Detected
- Attack_Type
- Decision
- Severity
- Confidence

The following scripts depend on these fields and **do not recalculate them**:

- correlation_analyzer.py
- privacy_score.py
- privacy_threat_analyze.py

---

## 4. correlation_analyzer.py

Analyzes correlations between identifiers and registration attributes to measure privacy linkability. It generates the correlation analysis report.

---

## 5. metadata_minimizer.py

Analyzes metadata exposure and creates an anonymized registration dataset by minimizing unnecessary metadata.

---

## 6. privacy_score.py

Calculates the overall privacy score for every registration using the processed dataset and generates the privacy report.

---

## 7. privacy_threat_analyze.py

Uses the attack context generated by `security_context.py` to identify potential privacy threats and generates the privacy threat report.

---

## 8. privacy_summary.py

Runs after all privacy analysis modules.

It aggregates the outputs from:

- correlation_analyzer.py
- metadata_minimizer.py
- privacy_score.py
- privacy_threat_analyze.py

and generates a consolidated `privacy_summary.txt`.

---

## 9. generate_privacy_graphs.py

Runs last.

It reads the processed privacy dataset and `privacy_summary.txt` to generate privacy visualization graphs. The generated graphs are saved in the `results/graphs/` directory.


# Evaluation

The evaluation module combines outputs from multiple teams.

It requires:

### From Privacy Team

Generated by:

```bash
python generate_privacy_context.py
```

Outputs:

* `privacy_context.csv`
* `privacy_context_summary.csv`

These are stored in:

```
results/eval_result/
```

---

### From Agent Team

* `agent_output.csv`

---

### From System Team

* `system_output.csv`
*  `system_execution.xlsx`

---

After all required files are available, run:

```bash
python evaluate.py
```

The evaluation reads:

* privacy_context.csv
* privacy_context_summary.csv
* agent_output.csv
* system_output.xlsx
* system_execution.xlsx

and generates the final evaluation reports inside:

```
results/eval_result/
```

along with the evaluation graphs.

---

# Complete Workflow

1. Run the privacy pipeline

```bash
python run_privacy_pipeline.py
```

2. Generate the privacy context

```bash
python generate_privacy_context.py
```

This creates:

* privacy_context.csv
* privacy_context_summary.csv

3. Make sure the following files are available:

* Privacy Team → privacy_context.csv
* Privacy Team → privacy_context_summary.csv
* Agent Team → agent_output.csv
* System Team → system_output.xlsx, system_execution.xlsx

4. Run evaluation

```bash
python evaluate.py
```

The final evaluation reports and graphs will be generated inside the evaluation results folder.


Produces final evaluation reports and evaluation graphs.
