# CAPSS Experiment Framework

## Supported Experiments

### Single UE

Measures registration behaviour for one subscriber.

### Multiple UE

Evaluates system behaviour under several simultaneous registrations.

### Congestion

Evaluates signalling behaviour under heavy load.

### Latency

Measures registration latency.

### Roaming

Evaluates roaming registration procedures.

## Experiment Workflow

1. Cleanup
2. Start Core
3. Verify Core
4. Start gNB
5. Start UE(s)
6. Collect Logs
7. Parse Logs
8. Generate Reports
9. Save Results
